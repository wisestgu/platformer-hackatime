# Haven Hopper

A 2D platformer built with Python and Pygame.

**Play in your browser:** https://wisestgu.github.io/platformer-hackatime/

## Run locally

```
pip install pygame
python haven.py
```

## Controls

| Action | Keys |
|---|---|
| Move | Arrow keys or A / D |
| Jump | Space, W or Up |
| Pause | Esc |
| Quit to menu (while paused) | Q |
| Select (menus) | Enter |
## Saving

Your high score and best level are saved automatically: in `save.json` next to the game when run locally, or in your browser's storage on the web version.
